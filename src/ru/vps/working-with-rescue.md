# Работа в режиме восстановления

## Загрузка в режиме восстановления

Загрузить сервер в режиме восстановления можно двумя способами:

### С помощью кнопки "Режим восстановления"

1. Войдите в свою учетную запись в [панели управления сервером](https://vm.senko.digital/).
2. Выберите сервер, на котором необходимо включить режим восстановления.
3. Нажмите на три точки в списке серверов или на странице параметров сервера, затем выберите "Режим восстановления".
![Режим восстановления в меню](/images/vps/recovery/rescue-recovery-mode-ru.png){data-zoomable}
4. Нажмите кнопку "Запустить режим и перезагрузить".
![Кнопка включения режима восстановления](/images/vps/recovery/rescue-enable-recovery-mode-ru.png){data-zoomable}

После того как статус сервера изменится на "Активна", подключитесь к серверу через VNC.

Для настройки сети воспользуйтесь [инструкцией по настройке сети в SystemRescue](#systemrescue).

### С помощью ISO

1. Войдите в свою учетную запись в [панели управления сервера](https://vm.senko.digital/).
2. Выберите сервер, на котором необходимо смонтировать ISO-файл.
3. Нажмите на три точки в списке серверов или на странице параметров сервера, затем выберите "Подключить ISO-образ".
![Кнопка монтирования ISO-образа в меню](/images/vps/recovery/rescue-iso-ru.png){data-zoomable}
4. Измените способ загрузки с "Локальный файл" на "URL образа".
5. Скопируйте ссылку для загрузки [GRML](https://grml.org/download/) или [SystemRescue](https://www.system-rescue.org/Download/) с соответствующей страницы загрузки.
6. Вставьте ссылку на один из ISO-файлов в поле "URL образа". Например:

- GRML: `https://download.grml.org/grml-full-2026.04-amd64.iso`
- SystemRescue: `https://fastly-cdn.system-rescue.org/releases/13.01/systemrescue-13.01-amd64.iso`
- Образ по вашему выбору

7. Нажмите "Загрузить образ".

::: warning
Обратите внимание на выбранный дистрибутив, поскольку от него зависит способ настройки сети. Если вы выбрали дистрибутив, которого нет в списке выше, ознакомьтесь с его документацией, чтобы правильно настроить сеть.
:::

После того как статус сервера изменится на "Активна", подключитесь к серверу через VNC.

Для настройки сети воспользуйтесь инструкцией для выбранного дистрибутива: [SystemRescue](#systemrescue) или [GRML](#grml).

## Настройка сети

### SystemRescue

В SystemRescue сеть настраивается через интерфейс командной строки NetworkManager. Перед настройкой получите сетевые параметры сервера в разделе "IP-адреса" панели управления сервером. Вам потребуются:

- IP-адрес
- Шлюз

Получив эти данные, выполните следующие команды:

#### 1. Настройте IP-адрес

```bash
nmcli conn mod "Wired connection 1" ipv4.addr <IP>/32
```

Замените `<IP>` на IP-адрес вашего сервера.

#### 2. Отключите DHCP

```bash
nmcli conn mod "Wired connection 1" ipv4.method manual
```

#### 3. Настройте шлюз

```bash
nmcli conn mod "Wired connection 1" ipv4.gateway <GATEWAY>
```

Замените `<GATEWAY>` на шлюз вашего сервера (обычно `172.16.0.1` или `10.0.0.1`).

#### 4. Настройте DNS

```bash
nmcli conn mod "Wired connection 1" ipv4.dns 1.1.1.1
```

#### 5. Включите интерфейс

```bash
nmcli conn up "Wired connection 1"
```

#### 6. Включите SSH-сервер

```bash
systemctl enable ssh --now
```

Затем можно [настроить firewall](#настройка-firewall), чтобы разрешить входящие SSH-подключения к серверу.

### GRML

Настроить сеть можно с помощью утилиты `grml-networking`. Запустите ее командой `grml-networking` или нажатием `n` после первоначальной загрузки. Перед настройкой получите сетевые параметры сервера в разделе "IP addresses" панели управления сервера. Вам потребуются:

- IP-адрес
- Маска
- Шлюз

После запуска утилиты:

1. Выберите `netcardconfig` и нажмите `[Enter]`.
2. На вопрос о настройке VLAN выберите `No`.
3. На вопрос об использовании широковещательного запроса DHCP выберите `No`.
4. Введите IP-адрес сервера и нажмите `[Enter]`.
5. Введите маску сети сервера (обычно `255.255.255.255`) и нажмите `[Enter]`.
6. Оставьте широковещательный адрес пустым. Если в этом поле указан ваш IP-адрес, удалите его, затем нажмите `[Enter]`.
7. Введите шлюз сервера (обычно `172.16.0.1` или `10.0.0.1`) и нажмите `[Enter]`.
8. Введите `1.1.1.1` в качестве DNS-сервера. Вместо него можно использовать другой DNS-сервер. Затем нажмите `[Enter]`.
9. На вопрос об автоматическом включении интерфейса при загрузке выберите `Yes` или `No`.

После этого вы вернетесь в первоначальное меню. Выберите `Quit`, а при появлении приветственного сообщения нажмите `q`.

#### Включите SSH-сервер

```bash
systemctl enable ssh --now
```

Затем можно [настроить firewall](#настройка-firewall), чтобы разрешить входящие SSH-подключения к серверу.

## Настройка firewall

#### 1. Очистите существующие правила

```bash
iptables -F
```

#### 2. Разрешите трафик уже установленных и связанных с ними соединений

```bash
iptables -I INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT
```

#### 3. Разрешите все входящие SSH-подключения

```bash
iptables -I INPUT -p tcp --dport 22 -j ACCEPT
```

#### 4. Разрешите трафик интерфейса обратной петли

```bash
iptables -I INPUT -i lo -j ACCEPT
```

## Использование режима восстановления

В этом разделе описаны распространенные операции, выполняемые в режиме восстановления.

### Доступ к данным на диске сервера

Сначала [настройте сеть](#настройка-сети) и [правила firewall](#настройка-firewall). Затем выполните следующие действия.

#### 1. Найдите диск сервера

Сначала определите диск сервера с помощью команды:

```bash
lsblk -f
```

Найдите раздел с данными сервера. В столбце FSTYPE для него должно быть указано `ext4`:
![Вывод команды lsblk](/images/vps/recovery/rescue-lsblk.png){data-zoomable}

#### 2. Создайте точку монтирования и смонтируйте диск

Создайте точку монтирования:

```bash
mkdir -p /mnt/vm
```

Затем смонтируйте раздел:

```bash
mount /dev/vda3 /mnt/vm
```

Убедитесь, что раздел смонтирован правильно:

```bash
ls /mnt/vm
```

В корневой файловой системе Linux обычно отображаются следующие каталоги:
![Пример смонтированного диска](/images/vps/recovery/rescue-mounted-disk.png){data-zoomable}

Теперь можно подключиться к серверу с помощью SFTP-клиента (например, WinSCP), используя учетные данные SSH, и редактировать или скачивать файлы с диска сервера.
