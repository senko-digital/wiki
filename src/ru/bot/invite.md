# Приглашение бота на свой сервер

Чтобы пригласить бота на свой сервер, перейдите по [этой ссылке](https://discord.com/oauth2/authorize?client_id=1179024014195310592), выберите опцию "Добавить на сервер" и выберите сервер, на который хотите добавить бота, и следуйте дальнейшим инструкциям.
